# RAG по игровым телеграм каналам

Сквозной RAG-проект с курса LLM-инженер. Корпус: посты из двух телеграм каналов про игры, @egs_tg (Epic Games Store) и @SteamByFree (Халявный Steam).

Каждая контрольная точка лежит в своей ветке:
- kt1: корпус и золотой набор
- kt2: предобработка, чанкинг и метаданные
- kt3: векторная база, эмбеддинги, sparse, dense и hybrid поиск
- kt4: трансформация запросов и реранкинг
- kt5: генерация, оценка качества и продвинутый RAG
